# GestionFormation

## About the Project

GestionFormation is a PHP-based training management project developed as part of my learning journey in web development and database management.

The application allows users to view available training courses, consult their details, filter courses by level, and access the registration process.

## Features

- Display available training courses
- View course details
- Filter courses by difficulty level
- Access the registration page
- Retrieve information from a database

## Technologies

- PHP
- PDO
- MySQL
- HTML
- CSS

## Project Structure

- `formations.php` – Displays available training courses.
- `inscription.php` – Registration page.
- `profil.php` – Profile page.
- `traitement.php` – Form processing.

## Note

This project is an academic exercise designed to practice PHP and database interaction.
